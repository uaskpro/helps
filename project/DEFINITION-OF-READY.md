# Definition of Ready — helps

Version: 0.1.0 · Owner: lead · Last changed: 2026-11-21

Work on a change starts when:

- [ ] It is classed fix, change or system change ([LIFECYCLE.md](LIFECYCLE.md)); a change or a
      system change has a release spec approved as `process.release-spec` requires.
- [ ] It names the requirement ids it serves, or adds them to the PRD first.
- [ ] Its acceptance criteria are written, including a case where helps refuses or fails safely
      when the change touches input, files, permissions or the network.
- [ ] It says which interface rows (blueprint §3) and building blocks (§5) it touches, and whether an
      interface change is compatible or breaking.
- [ ] Owner-level questions are answered, or asked with options and a default.
- [ ] It fits the appetite.
